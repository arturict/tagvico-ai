# Tagvico AI v3.4.1

Tagvico 3.4.1 is a dependency-security patch for stable v3. It carries no
application code changes.

## Highlights

- **Next.js critical RCE patched.** `next` is updated from `16.2.11` to
  `16.3.3`, the first release fixing a critical unauthenticated remote code
  execution advisory (GHSA-p293-qw3h-jr36, GHSA-2xp9-vwfh-vxw4).
- **Other high/critical audit findings cleared.** Dependency overrides bring
  `fast-uri` to `3.1.6` (host-confusion/SSRF advisories), `sharp` to `0.35.4`
  (libheif, GHSA-rgj7-g3m4-5g8c), and pin `js-yaml` to `4.3.2`
  (GHSA-2883-xcg3-v3hh) and `qs` to `6.16.0` (GHSA-x5fp-wj9c-mxmx,
  GHSA-4mjr-xmp4-gh2g), both pulled in transitively. `npm audit --omit=dev
  --audit-level=high` reports zero findings.
- **Documentation.** Contributor and agent operating instructions
  (`AGENTS.md`) were tuned for explicitly selected agents; no application
  behavior changed.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.4.1`, and recreate only the Tagvico container.
This is a v3 patch and does not require a data migration.
