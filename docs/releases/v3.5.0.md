# Tagvico AI v3.5.0

Tagvico 3.5.0 adds Sign in with ChatGPT, turns the start page into a chat, and
redesigns the interface in OpenAI's design language.

## Highlights

- **Sign in with ChatGPT.** An eligible ChatGPT Plus or Pro plan pays for
  filing, the Companion, tag unification and TypeSafe titles, without an API
  key. ChatGPT plan is listed first, with a New badge. GPT-6 Luna is
  preselected when your plan answers to it, otherwise the lightest listed
  model. See `docs/providers/chatgpt.md`.
- **Chat first.** Signing in opens a chat with suggestions built from your real
  documents and actions. Answers carry source pills, and proposed changes
  appear as approval cards.
- **Needs you.** One page for overdue and upcoming actions, approvals and
  review items across the household, with a filter per person.
- **People and cases.** Household members appear as an avatar row with open
  counts, each with their own page. Every case has a detail page.
- **Channels tab.** Telegram and Discord are configured in Settings with a
  token check, live status, allowed people and reminders.
- **Settings that take effect.** Saves reach the running server, the Paperless
  connection can be tested, and members and roles are managed in the UI.
- **New model picker.** One picker with provider rail, search, favourites and
  keyboard shortcuts in the chat header and in Settings.
- **New design.** Vendored Apps SDK UI tokens (MIT), system fonts, neutral
  colours. Phones use a top bar and a menu drawer.
- **TypeSafe Jev provider** for closed-list filing, and GPT-6 Luna as the
  recommended model for OpenAI direct and OpenRouter.

## Fixes and security

- Non-owners no longer receive installation settings.
- Empty Compose placeholders no longer lock the Telegram and Discord settings.
- Done dates, owner-token rotation and the Paperless connection test token
  scope were corrected.
- `fast-uri` 3.1.8 and `undici` 6.28.1 clear new high and moderate advisories;
  `npm audit --omit=dev --audit-level=high` reports zero findings.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.5.0`, and recreate only the Tagvico container.
This release does not change the data schema.

- **Compose channel variables.** The bundled `docker-compose.yml` now passes the
  `TELEGRAM_*` and `DISCORD_*` variables through empty. Copy the new file to
  edit those settings in the Channels tab. A value you set yourself, in your
  own Compose file or `.env`, still wins and is shown as set by the container
  environment.
- **Channels moved** from Automation to Settings -> Channels.
- **Navigation.** Sign-in opens the chat; the former Home dashboard is
  Overview in the account menu. There is no bottom tab bar on phones.
