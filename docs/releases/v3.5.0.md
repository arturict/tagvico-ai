# Tagvico AI v3.5.0

Tagvico 3.5.0 adds two providers to stable v3: your ChatGPT plan through
OpenAI's new Sign in with ChatGPT, and TypeSafe's Jev decision model. It does
not change the data schema.

## Highlights

- **ChatGPT plan (Sign in with ChatGPT).** An eligible ChatGPT Plus or Pro plan
  can now pay for document filing, the Companion, tag unification and TypeSafe
  titles, without an API key. Choose **ChatGPT plan** in Settings → AI models,
  select **Continue with ChatGPT**, allow Tagvico to use your plan, and paste
  the address of the `127.0.0.1` page ChatGPT opens (it does not load, because
  Tagvico runs on another machine). Usage counts toward your plan; you can
  limit or disconnect Tagvico under ChatGPT Settings → Usage, and **Sign out**
  revokes the session. Document text is sent to OpenAI with `store: false`.
  See `docs/providers/chatgpt.md`.
- **TypeSafe Jev.** A decision model for closed-list filing: it only picks
  existing tags, correspondents and document types and puts a probability on
  every field. Pair it with any text provider, including the ChatGPT plan, for
  titles and new senders. See `docs/providers/typesafe.md`.
- **GPT-6.** Luna recommendations move to `gpt-6-luna`; GPT-6 models no longer
  receive `temperature`, and reasoning effort is mapped to values they accept.
- **Security.** `fast-uri` 3.1.8 and `undici` 6.28.1 clear new high and
  moderate advisories.
- The Codex-based provider is renamed **ChatGPT via Codex (legacy)** and stays
  in maintenance mode.

## Upgrade

Back up the `tagvico_ai_data` volume, pin
`ghcr.io/arturict/tagvico-ai:3.5.0`, and recreate only the Tagvico container.
No data migration is required.
